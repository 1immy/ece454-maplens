# AGENTS.md

**Before doing anything in this repo, read [`project-AI-context.md`](project-AI-context.md).** It has the project scope, owners, schedule, module contracts, algorithm specs, test plan and PR template. Follow it.

Essentials, in case you read nothing else:

- Work only on the issue you were given, in its module. Changes to `core/model/`, `gradle/` or `.github/` need all three owners: propose them, don't make them silently.
- Branch from a fresh `main` (`feat/`, `fix/`, `docs/`, `data/`, `chore/`, `eval/`); Conventional Commits; never push to `main`.
- Tracking thresholds go in `TrackingConfig`; all geometry is in pixels of the straightened map.
- Add tests with every change and run `./gradlew ktlintCheck test` and `python -m unittest discover tools`. Say exactly what was and wasn't run.
- Don't edit hand-labeled fixtures (`*-corners.json`, traced `*.graph.json`) unless the issue is about them.
- Write the PR description from the template in `project-AI-context.md` §8, starting with `Closes #N`.
- No AI co-author trailers or "generated by" lines in commits or PRs; the team declares AI assistance separately.
