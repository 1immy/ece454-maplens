# Tools

Python notebooks and scripts that don't ship in the app:

- Parser prototyping (OpenCV in Python is faster to iterate on, then port to Kotlin)
- Graph-extraction F1 against hand-labeled graphs
- Trace replay and drift plots for conditions A–D
- User-study analysis

Use a virtual environment (`python3 -m venv .venv`, ignored by git) and pin dependencies in `tools/requirements.txt`.
